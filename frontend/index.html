How a check works

WhyDown follows the same path your browser takes and times every step. The step that fails is the reason the site is down.

DNS
Turns the website name into a server address. It fails when the name does not exist or its DNS is broken.
TCP
Opens a connection to that server. It fails when the server refuses the connection or does not answer.
TLS
Sets up the secure connection and checks the certificate. It fails when the certificate is expired or invalid.
HTTP
Asks for the page and reads the status code. An error code means the server is up but the page is not working.

What WhyDown can tell you

DNS problem

The website name could not be turned into an address.

Connection refused

The server was reached but did not accept the connection.

Timeout

The server did not answer in time.

Certificate error

The certificate is expired or invalid, so the secure connection fails.

HTTP error

The server answered with an error status code.

Slow

The site answered, but later than it should.
